Sobre los originales, el documento y este taller
Los cuatro archivos de programa se conservan sin cambios. Los adjuntos no identifican de forma verificable a sus autores: autoría y contribuciones del equipo pendientes de completar. La interfaz, los adaptadores de ejecución, las explicaciones y las pruebas fueron creados con asistencia de IA (OpenAI Codex).
Nota del enunciado: «Anita lava la tina» tiene 0 dígitos; el ejemplo del documento indica 2. El programa devuelve 0. El inventario permite nombre vacío; compra acepta infinito como precio: son comportamientos del original, no correcciones ocultas.
El adaptador suministra respuestas predefinidas y captura la consola. Al agotar entradas detiene el programa con un aviso. No modifica los algoritmos. El primer inicio descarga los runtimes; necesita conexión. Python usa un worker con límite de 20 segundos; C# admite hasta 1000 lecturas. No se guardan datos entre ejecuciones.
